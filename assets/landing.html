bmkg-edge

The shared BMKG layer for our projects. Indonesian earthquake, weather and severe-weather-warning data, parsed once, here, so nothing downstream parses it again.

Live Rust on Cloudflare Workers TypeScript client MCP endpoint MIT

Why this exists

BMKG publishes its data openly, but raw: numbers arrive as strings, one field holds "lat,lon" as text, forecasts nest three arrays deep, and warnings are CAP XML. So every project that wants BMKG data writes the same parsing again — and then each copy drifts, and each copy has to be fixed separately when BMKG changes something.

This is that parsing, done once, in one place. A project gets typed JSON and has nothing of its own to maintain. When BMKG moves, one repo changes.

The off-the-shelf alternative was a Python wrapper whose hosting lapsed — its demo answers 503 DEPLOYMENT_PAUSED and its MCP server proxies every tool call to that dead demo. Depending on someone else's free tier is the thing this avoids: no origin server, no paid plan, no machine to keep awake. One Cloudflare Worker serves the API, the MCP endpoint and this page.

Response shape

Every endpoint answers the same way, so you write one parser.

{ "ok": true,  "data": …, "meta": { "source": …, "cached_seconds": 60, "generated_at": … } }
{ "ok": false, "error": { "code": "upstream_not_found", "message": "…" } }

A 404 from BMKG becomes upstream_not_found, never an empty 200. If BMKG changes a payload shape, you get upstream_parse naming the URL — not silently wrong numbers.

Weather

BMKG keys forecasts by adm4, the Kemendagri village code. Three days of roughly 3-hourly slots, flattened into one ordered array.

GET/v1/weather/search?q=

Start here. Give it a place name and it resolves the code and returns the forecast in one call — plus what else the name could have meant.

Run
GET/v1/weather/{adm4}

Three-day forecast for one village.

Run
GET/v1/weather/{adm4}/current

The slot covering right now, plus the next three.

Severe-weather warnings

BMKG's nowcast feed. Detail responses carry the affected area as a polygon in GeoJSON order — [longitude, latitude]. CAP publishes lat,lon; the swap happens here so you can hand it straight to a map.

GET/v1/nowcast

All active warnings. ?lang=id for Indonesian.

Run
GET/v1/nowcast/check?location=

Warnings that mention a place. A text match over the live warning list.

Run
GET/v1/nowcast/{alert_code}

Full CAP detail: severity, urgency, certainty, validity window, polygon. Take the code from /v1/nowcast.

Regions

38 provinces, not 34. Indonesia split Papua into six provinces in 2022 and BMKG followed. The old Merauke code 91.01.01.2001 now returns 404 upstream; the current 93.01.01.2001 is the same village. This API uses the current Kemendagri list, so Papua works.

Use it from a project

Copy client/bmkg.ts from the repo. Zero dependencies, no build step, works in a Worker, a browser and Node 18+.

import { createBmkg } from "./bmkg";

const bmkg = createBmkg();

const quake = await bmkg.earthquake.latest();
quake.magnitude;            // 6.2 — a number, not "6.2"

const w = await bmkg.weather.find("tebet");
w.matched.path;             // "…› Tebet › Tebet Barat"
w.forecast.slots[0].temperature_c;

From another Cloudflare Worker

Bind to it as a service and the call never leaves the edge — no public round trip, no DNS, no TLS handshake.

# the consumer's wrangler.toml
[[services]]
binding = "BMKG"
service = "bmkg-edge"
const bmkg = createBmkg({ fetcher: env.BMKG });

Failures are typed

try {
  await bmkg.weather.byCode("99.99.99.9999");
} catch (e) {
  if (e instanceof BmkgError && e.isMissingUpstream) { /* valid code, BMKG has no data */ }
  if (e instanceof BmkgError && e.isSchemaDrift)     { /* BMKG moved — bmkg-edge needs a fix */ }
}

Watching it

/health/deep exercises every upstream and reports each one. It answers 503 when any source fails, so a cron can watch one URL. That is the failure that matters here — not the Worker going down, but BMKG changing a payload while every response stays 200.

Self-hosting

One Worker and one D1 database, both inside Cloudflare's free tier. Steps are in the repo README.
